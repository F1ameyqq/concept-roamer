# 概念漫游 0.2.5

面向 Windows 与 Android 的 Obsidian 插件。支持流式讨论、概念笔记整理、关联已有笔记、会话摘要、可编辑人格与手动全局记忆。

0.2.5 增加选文讨论：在笔记中选中文字，右键点击“在漫游中讨论”，把原文和来源带入聊天。输入问题后发送，后续追问、自动标题、整理与导出继续保留引用。支持编辑、实时预览及阅读模式；Android 可使用“在漫游中讨论选中文字”命令。

0.2.4 修复 0.2.3 的 Windows 流式请求：桌面 HTTPS 模块在构建时转换为受平台判断保护的 CommonJS 加载，避免浏览器尝试解析模块名称。运行错误会显示具体原因；Web 请求的连接错误单独提示。

0.2.3 增加自动会话标题：首轮完整回复后根据内容命名，之后每增加三轮完整回复更新。命名在后台进行；手动固定的标题不会更改，失败时保留当前标题。打开已有的完整会话也可自动命名。

0.2.2 将插件列表名称改为 **Concept Roamer**，符合社区目录的 Basic Latin 命名要求。聊天界面、命令和知识库目录继续使用中文。

0.2.0 增加“整理并保存”：使用当前模型把当前分支讨论重新整理成概念笔记，预览和编辑后保存；同时生成可追溯的会话摘要。“导出原文”继续保存原始对话。

0.1.2 修复启动或同步期间索引尚未加载时重复创建已有目录的问题。初始化等待工作区加载，目录和文件存在性通过实际存储复核，历史 JSON 的发现不依赖文件列表的显示设置。

0.1.3 新回复开始时显示回复开头，生成期间保留阅读位置；主动向下滚到底部或点击“查看最新”后跟随新内容，向上阅读时暂停跟随。AI 气泡顶部的角色与状态字样已去除。

## 安装

1. 使用 Obsidian 1.11.4 或更新版本。
2. 把压缩包中的 `concept-roamer` 整个文件夹放入目标知识库的 `.obsidian/plugins/`。
3. 重启 Obsidian，在“设置 → 第三方插件”中启用“Concept Roamer”。
4. 打开“设置 → Concept Roamer”，在密钥控件中创建或选择 DeepSeek API Key。
5. 默认模型为 `deepseek-flash`，可改为账户支持的模型名称。

## 使用

- 点击侧栏图标或命令“概念漫游：打开聊天”。
- 在笔记中选中文字，右键点击“在漫游中讨论”。复用已打开的聊天；没有聊天时，Windows 打开悬浮窗，Android 打开聊天页。原来的输入草稿会保留。
- 输入框上方显示引用卡片，可点击笔记名称回到来源，或点“移除”。写下问题再发送；直接发送引用会请求解释这段文字。已有回复生成期间也可以准备下一段引用。
- Android 选中文字后，可在命令面板使用“在漫游中讨论选中文字”。实际手机选区菜单仍需真机验证。
- 选区最多 8,000 字符，问题与引用合计最多 20,000 字符。点击发送后，选文、笔记标题和库内相对路径随问题发送到 DeepSeek。聊天流程仅使用已选文字。
- 聊天顶部、历史列表和原文导出显示会话标题。点击“标题”可手动改名，默认固定标题；勾选“允许自动更新这个会话标题”可让后续讨论继续更新它。
- “设置 → Concept Roamer → 自动更新会话标题”可关闭自动命名。每次命名额外调用 DeepSeek，发送开头和近期对话片段，按 API 计费，不发送人格或记忆文件。
- Windows：命令“概念漫游：打开桌面悬浮聊天窗”打开独立窗口，可拖动和缩放。在弹出窗口中使用 Obsidian 自带“切换窗口置顶 / Toggle always on top”命令。
- Android：使用应用内聊天页面。首次真实调用需要自行验证设备 WebView 的流式兼容性。
- Enter 发送，Shift + Enter 换行；Ctrl / Command + Enter 也可发送。中文输入法选字时的回车不会发送；Android 可点击“发送”。
- 点击“停止”取消网络请求。已经收到的文字保存为“已停止”，不会作为完整 AI 回答加入后续上下文。
- “人格”和“记忆”打开库内 Markdown 文件，修改在下一次发送时生效。
- “历史”重新打开会话，“分支”选择同步后出现的不同讨论路径。
- “整理并保存”：可填写概念名称，或留空让模型识别。点击“开始整理”，检查预览，必要时切换“编辑 Markdown”，再点击“保存到知识库”。
- 概念笔记包含定义、机制、例子、边界、应用及未决问题；你的观点只引用你实际说过的原文。
- 整理时通过标题和别名寻找最多 8 篇相关 Markdown 笔记，只发送这些笔记的开头片段。模型最多选择 6 条具体关联，保存为双向链接。
- 笔记保存到 `概念漫游/概念/`，同名文件会新建带唯一后缀的副本。摘要保存在相应会话的 `整理摘要/` 中。
- 整理草稿和编辑内容在本机保存，关闭窗口后可重新打开继续编辑。保存失败可以重试。
- “导出原文”保存当前分支的完整原始对话。

## 数据与同步

数据在 `概念漫游/` 目录；每条消息是独立 JSON，带唯一 ID 和父消息 ID。人格及手动记忆是 Markdown。原始消息不会覆盖已有不同内容。

选文引用单独保存在用户消息的 noteQuote 字段中，含原文、笔记名称和路径；问题正文保留实际输入。追问与重载继续使用引用，导出保留来源链接。整理时不能仅凭引用推断这是你已认同的观点；来源笔记作为关联候选时使用已选原文。

使用 Obsidian Sync 时，需要启用其他文件类型以同步 JSON。插件安装同步需要相应的社区插件同步设置。API Key 通过 Obsidian SecretStorage 本机配置，插件 `data.json` 只保存密钥名称。

标题修订以独立 JSON 保存，不覆盖原始会话元数据和消息。同一标题版本发生并发修改时，手动修改优先于模型修改；缺少前序修订时等待同步。

流式草稿每隔约半秒保存到本机 localStorage，正常结束后写入知识库。关闭或重启导致的未完成回复，下次启动会尝试恢复；突然断电仍可能损失最后一个保存间隔内的文字。

第一版的全局记忆是同一知识库内跨会话读取的手动记忆文件，尚未加入自动提取、逐条检索和修订记录。同一人格或记忆文件同时在两台设备编辑时，应通过同步工具处理冲突。

聊天将人格、手动记忆和当前分支的有效历史发送到 DeepSeek。整理笔记还会发送最多 8 篇相关笔记的开头片段。上下文超预算时提示新建会话，不静默截断。

## 验证范围

- Windows 使用 Node HTTPS 原生流读取；Android 使用 fetch + ReadableStream，两者共用 SSE 解码器。
- 收到真实网络片段后立即显示文字，没有模拟打字效果。
- 不自动切换为非流式请求。
- 输出中的 Markdown 在回复结束后渲染；生成时按收到的正文显示。
- 默认关闭思考模式以缩短首字等待。开启时显示思考状态，不保存推理过程。
- 请求总时限为 5 分钟，无自动付费重试。超时或中断保留部分正文并标记状态。
- 当前代码检查与本地模拟流测试不代表已完成 Obsidian 真机或真实 DeepSeek 账户验收。

来源只允许使用对话中已经出现的 URL，并标记“待核验”。本版没有自动联网核验来源。自动记忆候选、长会话上下文压缩和无损归档压缩仍待后续实现。

## 开发

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run build
```

构建输出位于 `dist/concept-roamer`。源码包含网络流、取消、中断、UTF-8 分包及会话分支测试。

## 真机验收

1. 分别在 Windows、Android 发起一个较长回复，确认完整结束前已经出现正文。
2. 在生成中停止，确认立即停止接收、按钮恢复、部分正文重启后保留。
3. 主动断网，确认显示中断而非完整结束，已有文字仍保存。
4. Windows 将聊天弹出、置顶，切换到其他应用后确认可用。
5. 修改人格与记忆，新建会话并检查下一次请求是否使用新内容。
6. 两台设备离线续聊同一会话，再同步，检查两条分支是否都保留。
